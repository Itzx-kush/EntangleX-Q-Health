# SIH26139 Requirement Matrix

The authoritative machine-readable matrix is served by `GET /api/platform/validation/matrix`. The Governance & delivery workspace renders and exports it. Each row maps: requirement → feature → API → UI screen → test → evidence artifact → demo step → limitation.

The matrix covers biomedical ingestion, hybrid quantum-classical models, rigorous comparison, explainability, prediction/decision support, privacy/scalability, hardware readiness and final delivery. Operators must attach licensed dataset provenance and actual CI/demo evidence before presenting the package externally.
